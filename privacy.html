Privacy policy

Last updated: 2026-11-13

What this app is

rclone-thinkpad is a personal OAuth client used by rclone, an open-source file sync tool, so that the owner can access their own Google Drive from their own computer. It has a single user: the owner.

Data accessed

The app requests access to Google Drive in order to list, read and write the owner's own files. Access tokens are stored only on the owner's computer, in an encrypted configuration file.

Data collected or shared

No data is collected, stored on any server, sold, or shared with third parties. Files move only between the owner's computer and the owner's Google Drive.

Use of Google user data

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.

Contact

Through the GitHub profile that hosts this page.
